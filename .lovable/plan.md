# تدقيق فهرسة سما وإصلاح صفحات الأطفال

- حصر صفحات المحتوى العامة ومراجعة الوصف وcanonical ومنع الفهرسة والروابط، دون افتراض أن sitemap سبب المشكلة.
- إضافة وصف عربي قصير وفريد للصفحات العشر للأطفال، مع وصف متسق للمشاركة.
- إضافة روابط سياقية حقيقية في أسفل الصفحات للسابق والتالي والفهرس واللعبتين، دون تغيير أزرار الأنشطة أو شروط إكمالها أو القصص والصوت والصور وCSS.
- الحفاظ على sitemap الحالي، وعدم إضافة `/sources` إذا بقي تحويلًا إلى `/about`؛ حينها يظل العدد 34 بدل 35. لا تُضاف تحويلات `/kids` و`/teens`.
- اختبار XML والأوصاف والعناوين وcanonical وغياب noindex وصحة وجهات الروابط، ومقارنة المحتوى والوسائط وCSS قبل وبعد، ثم فحص العرض والتنسيق والفحوصات المتاحة.
- تقديم قائمة الصفحات والملفات المعدلة والنتائج والحدود، دون نشر أو ادعاء ضمان فهرسة Google.

## تفاصيل تقنية
- توثيق قاعدة روابط الأطفال في AGENTS.md وإضافة اختبار انحدار محافظ.
- بناء الإنتاج يُنفّذ تلقائيًا بواسطة بيئة المشروع؛ تُراجع نتيجته دون تشغيل بناء يدوي مكرر.
