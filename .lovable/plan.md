# خطة تدقيق تجاوب موقع سما بالكامل — قراءة فقط

## النطاق المؤكد
- مراجعة جميع الوجهات العامة المعروفة: **12 مسارًا للتطبيق** (بما فيها التحويلات وملف خريطة الموقع)، **10 صفحات لعالم الأطفال**، و**16 صفحة لعالم الشباب**؛ المجموع الأولي **38 وجهة**.
- تنفيذ المراجعة محليًا على خمسة مقاسات فعلية: `375×812` و`390×844` و`768×1024` و`820×1180` و`1024×768`.
- عدم تعديل أي ملف أو نشر الموقع أو تحديث `roadmap` أو `AGENTS`.

## خطوات التدقيق
1. **بناء سجل تغطية**
   - فتح كل وجهة مباشرة وتسجيل: الحالة، عنوان الصفحة، اكتمال التحميل، وأي خطأ في الشاشة أو وحدة التحكم أو الشبكة.
   - التحقق من وجهات التحويل مثل `/kids` و`/teens` و`/sources` بدل عدّها ناجحة لمجرد حصول التحويل.

2. **فحص بصري وتفاعلي لكل مقاس**
   - تصوير كل صفحة عند المقاسات الخمسة دون استخدام لقطة طويلة تخفي موضع المشكلة.
   - فحص عرض الصفحة كاملًا، لا التمرير الأفقي فقط: القص، التداخل، انضغاط النص، خروج العناصر، نسب الصور، ترتيب البطاقات، المسافات، وثبات شريط التنقل.
   - قياس أهداف اللمس الظاهرة وتسجيل المخالفة الفعلية فقط، مع مراعاة الروابط المتجاورة والمساحة القابلة للنقر.

3. **اختبار الحالات التفاعلية**
   - المنصة الأساسية: قائمة «المزيد» بالجوال، البحث ونتائجه، الطوارئ، مشغلات الصوت، وضع التركيز، الاختبارات، نماذج تخصيص أدوات الأسرة، نسخ النص، وروابط/أزرار التنزيل.
   - الدليل والدروس: بطاقات الفصول، التنقل بين المحتوى، الصور، عناصر التوسيع أو الاختبارات، والجداول إن وجدت.
   - عالم الأطفال: بوابة البداية، خريطة المغامرات، الصفحات الداخلية، الصوت، الفيديو، ولعبتا «مفاتيح الطاقة» و«طريق سما» بما يشمل بدء اللعب والحالة بعد التفاعل.
   - عالم الشباب: القائمة في حالتي الفتح والإغلاق، الصفحة الرئيسية، الرحلة، الدروس العشرة، السلامة، الإيمان، الأسئلة، وعن العالم؛ وفحص الوسائط والتنقلات الداخلية.

4. **توثيق المشكلات بالدليل**
   - لكل مشكلة مؤكدة فقط: الخطورة، المسار، المقاس، خطوات الإظهار، العنصر المتأثر، الأثر على المستخدم، ولقطة مقصوصة واضحة تحمل اسمًا فريدًا.
   - إعادة المشكلة مرة ثانية قبل إدراجها، وفحصها على مقاس مجاور لتحديد نطاقها.
   - عدم تسجيل اختلافات ذوقية أو استنتاجات بلا أثر مرئي/وظيفي.

5. **التقرير النهائي**
   - ترتيب النتائج: حرجة، عالية، متوسطة، منخفضة.
   - ذكر عدد الوجهات والصفحات وحالات التفاعل والمقاسات المغطاة، وما تعذر اختباره وسببه.
   - إرفاق جدول بالمشكلات الفعلية وروابط لقطات الدليل، ثم ملخص لما اجتاز الفحص دون الادعاء بأن غياب التمرير الأفقي وحده يعني سلامة العرض.

## حدود المراجعة
- التدقيق على نسخة المعاينة المحلية الحالية، بلا أي تعديل أو إصلاح أو نشر.
- الروابط الخارجية مثل يوتيوب وأرقام الاتصال تُفحص من حيث ظهورها واستجابتها داخل الصفحة، دون تنفيذ اتصال أو اعتماد نجاح خدمة خارجية.
- فحص قارئ الشاشة الكامل والأجهزة المادية خارج النطاق؛ يشمل التدقيق مؤشرات المتصفح القابلة للقياس مثل الأسماء المتاحة وأهداف اللمس والتركيز المرئي.
